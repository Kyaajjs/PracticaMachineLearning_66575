Cómo ejecutar y revisar el código
  1. Elige un ejemplo, carga una muestra y pulsa Ejecutar predicción. Puedes editar todos los valores de entrada.
  2. Usa Evaluar todo el test para obtener métricas nuevas sobre el conjunto reservado.
  3. Para volver a entrenar, descarga el proyecto completo, descomprime e instala las dependencias con python -m pip install -r requirements.txt.
  4. Desde la carpeta programas, ejecuta . Los pesos, métricas y gráficas se guardan en resultados.
  5. En Google Colab: Archivo → Subir cuaderno → selecciona el notebook del ejemplo → Entorno de ejecución → Ejecutar todas. Necesita conexión a internet.
